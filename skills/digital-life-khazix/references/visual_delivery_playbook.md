# 按需图文交付 Playbook

这份 reference 只在用户明确要求「配图」「图文版」「生成图片」「图片方案」时使用。长回答和公众号长文的默认交付只输出成稿，不附配图、插入位置或图片提示词。

配图不是装饰。它只服务三件事：

- 让读者更快进入开篇场景。
- 帮读者理解正文里最关键的关系、机制或责任链。
- 把文章的可复用动作、边界判断或结尾选择落成一个视觉锚点。

## 1. 触发条件和交付顺序

只有用户明确要求配图、图文版或生成图片时，按这个顺序输出：

1. 成稿。
2. 配图，至少三张。
3. 插入位置，逐张说明插在哪个段落、标题或具体句子之后。

如果用户只是说「写回答」「写文章」「出稿」「帮我写」，不要启用本 reference，不要追加配图方案。

不要先解释写作思路，也不要把配图说明插进成稿正文。成稿要保持可以直接复制发布。

如果当前环境能调用图片生成工具，优先实际生成图片。生成后按「图一、图二、图三」编号展示；如果工具返回本地路径，就附上图片或路径。如果当前环境不能生成图片，给出可直接用于生成或搜索的配图方案，并明确说明未实际生成。

## 2. 三张图的功能分工

### 图一：开篇入口图

放在文章开头第一个判断或第一个场景之后。它负责让读者进入问题，不负责讲完观点。

适合：

- 公共事件：克制的现场氛围、地点、物件、背影、距离感。
- 职场：工位、会议室、工作群、招聘软件、绩效表。
- 情感：饭桌、聊天框、转账记录、门口沉默。
- AI 和产品：真实操作界面、工作台、文件夹、会议记录、测试过程。

### 图二：正文解释图

放在文章开始拆机制、责任链、边界判断、工作流变化之后。它负责帮读者理解「为什么会这样」。

适合：

- 责任链、流程链、因果链。
- 前后对照。
- 三个角色之间的成本转移。
- 工具使用步骤或产品适用场景。

### 图三：行动或收束图

放在文章靠后，通常是给出可复用判断、步骤、避坑点或结尾选择之前后。它负责让读者记住能带走的东西。

适合：

- 普通人下一步该怎么做。
- 一个边界问题停在哪里。
- 一个收藏锚点的视觉化。
- 一个更克制的情绪落点。

## 3. 插入位置怎么写

每张图都必须给具体锚点：

- 可以写「插在『法律看的是行为链』这一段之后」。
- 可以写「插在小标题『越是害怕被讹，越要做对动作』下面」。
- 可以写「插在成稿第 5 段，也就是『报警，打120，留在现场』之后」。

不要只写：

- 开头。
- 中间。
- 后面。
- 责任部分附近。

如果文章没有小标题，就引用段落首句或关键句。位置说明要让用户不用重新判断就能直接粘贴。

## 4. 公共事件和高风险题材

遇到交通事故、伤害、医疗、未成年人、灾害、刑事案件和最新新闻时，配图必须守事实边界：

- 不生成血腥、伤口、死亡、施暴特写。
- 不复刻受害者、嫌疑人或未成年人的可识别面部。
- 不把网传细节画成已确认事实。
- 不使用真实监控截图风格冒充证据。
- 可以用非血腥现场、物件、距离、救助动作、责任链图、法庭或医院门口等克制表达。

如果用户要求刺激、猎奇或血腥配图，改成新闻评论可发布的克制图，并说明为了避免二次伤害和审核风险，配图不做血腥复刻。

## 5. 图片提示词写法

提示词要包含五个要素：

1. 文章类型：知乎/公众号社会评论、产品体验、AI 工具实测等。
2. 场景主体：地点、物件、人物距离或界面状态。
3. 不能出现的内容：血腥、可识别面孔、具体隐私、未证实细节、文字。
4. 风格：纪实、编辑插画、产品截图风、克制新闻评论、温和生活感。
5. 画幅：默认横版 16:9，适合文章头图和正文插图。

优先生成位图图片，不要用纯 SVG 或抽象渐变糊弄配图。除非用户明确要流程图，否则不要把图做成文字堆砌。

## 6. 输出格式

用户明确要求配图时，成稿之后使用这个格式：

```markdown
**配图**

图一：[图片或路径]
用途：……
插入位置：插在「……」之后。

图二：[图片或路径]
用途：……
插入位置：插在「……」之后。

图三：[图片或路径]
用途：……
插入位置：插在「……」之后。
```

如果生成了超过三张图，也按功能排序，不要把相似图全部堆给用户。明确要求配图时至少三张，不必为了数量牺牲准确性。
