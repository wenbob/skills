# 文章模式路由和内部写作卡片

这份 reference 用来解决一个问题：同样是长文，不同题目需要不同的主目标。不要让一篇文章同时追求所有传播结果，最后既不像故事，也不像方法文。

## 1. 先选文章模式

### 讨论型

适合社会议题、职场争议、情感边界和热点评论。

主要目标：让读者补充经历、讨论边界或替另一种处境说话。

优先动作：

- 前 300 字直接给判断和一个具体处境。
- 主动承认另一边最合理的顾虑。
- 留一个没有被彻底封死的现实问题。
- 收藏锚点只保留一个边界判断或责任链，不硬塞清单。

### 实用型

适合工具分享、教程、AI 使用方法、职场方法和产品避坑。

主要目标：让读者觉得以后还会回来查。

优先动作：

- 先从一个真实麻烦进入，不要从功能清单进入。
- 给出步骤、适用条件、失败条件和翻车点。
- 说明这套方法解决哪个明确问题，不要把资料清单当成干货。
- 每个建议指向具体对象和具体动作。
- 评论入口优先用方法追问或经验补充。

### 故事型

适合调查实验、产品实测、人物故事和自带动作线的公共事件。

主要目标：让读者沿着过程读下去。

优先动作：

- 用动作、对话、时间点或结果倒放开门。
- 每次推进都增加一个新发现、新后果或新问题。
- 判断不要抢在故事前面，把重量留到关键节点。
- 结尾回到开头的人、物件或选择。

### 混合型

适合既有故事又有方法，或者既要讨论又要提供行动建议的题目。

只允许一个主要目标。内部先写清：

> 这篇文章主要是 ______ 型。其他内容只服务于 ______。

例如，AI 工具实测可以以故事型为主，方法步骤作为收藏锚点；职场争议可以以讨论型为主，决策清单只在结尾克制出现。

## 2. 再填写内部写作卡片

动笔前在内部快速回答，不要向用户展示：

1. **题目类型**：社会、职场、情感、热点、AI 科技、产品体验，还是其他。
2. **文章模式**：讨论型、实用型、故事型，还是以其中一种为主的混合型。
3. **目标读者**：谁最可能停下来继续读，不要只写“普通人”。
4. **读者镜像**：他最容易认出自己的哪个瞬间。
5. **两难成本**：他卡在哪两个代价之间。
6. **直接回答**：前 300 字必须给出的核心判断是什么。
7. **事实边界**：哪些是事实、材料说法、合理推断和条件场景。
8. **评论入口**：读者最自然的接话方式是什么。
9. **收藏锚点**：一周以后，读者回来找哪一个判断、步骤、案例或表达。
10. **原创转化**：原始素材经过你之后，多了什么组织、解释、取舍、判断或方法。
11. **论据支撑**：核心观点靠什么托住，不能只写态度和结论。
12. **结构变化**：这次主动避开什么近期常用开头、推进方式和结尾方式。

卡片的作用是做选择，不是让文章机械出现十个模块。

## 3. 模式和题材如何组合

| 题材 | 默认模式 | 可以切换的条件 |
| --- | --- | --- |
| 社会议题 | 讨论型 | 材料自带完整动作线时切故事型 |
| 职场题 | 讨论型 | 用户明确求方法时切实用型 |
| 情感题 | 讨论型 | 用户要求解决方案时切实用型 |
| AI 科技 | 故事型或实用型 | 有亲自实测过程时优先故事型 |
| 产品体验 | 故事型 | 用户需要购买建议时增加实用锚点 |
| 热点评论 | 讨论型 | 事件有调查过程时切故事型 |

## 4. 选错模式时怎么返工

- 文章一直讲道理，没有人站出来：从讨论型空转了，补读者镜像和动作。
- 文章列了很多知识点，但读者不知道为什么要看：实用型缺真实麻烦，重写入口。
- 文章看起来有干货，但只是在搬运信息：缺原创转化，补解释、取舍和可复用判断。
- 文章观点很明确，但读者不信：缺论据支撑，补材料细节、案例、对比或经验。
- 文章有很多情绪，但没有推进：故事型缺新发现或新后果，删掉重复抒情。
- 文章既想讲故事又想教教程又想上价值：混合型没有主目标，删到只剩一条主线。
