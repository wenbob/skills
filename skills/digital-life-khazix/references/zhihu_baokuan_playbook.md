# 知乎爆款回答 Playbook

这份 reference 用来把回答写得更有代入感、认同感和评论欲。不要把它当固定模板照抄，它提供的是写作动作。

## 1. 代入感公式

身份标签 → 具体处境 → 具体动作 → 内心拉扯 → 读者映射

**身份标签**：先知道是谁，比如应届生、基层干部、宝妈、程序员、销售、县城青年。

**具体处境**：他在什么环境里，出租屋、工位、医院走廊、训练场、饭桌、工厂宿舍、招工群。

**具体动作**：不要只写「焦虑」「痛苦」「努力」，要写他怎么表现出来。比如反复刷新招聘软件、把聊天框打了又删、以身体不适申请休息、晚上十一点还在改 PPT。

**内心拉扯**：他不是单纯好或坏，而是在两个代价之间卡住。想体面，但没资源；想离开，但怕损失；想负责，但又撑不住。

**读者映射**：最后轻轻把读者拉进来，让他发现这不是别人的故事。

示例动作：

> 一个刚毕业的年轻人，不一定是突然变懒了。他可能只是第一次发现，学校里那套「努力就会被看见」的规则，到了公司里根本不稳定。晚上十一点，他把简历又改了一遍，投出去之前还要想，这个城市我到底还能不能留下。

## 2. 评论欲公式

温和争议点 + 双方合理性 + 一个未完全封死的问题

爆款回答要给读者留出接话的空间，不必把所有话说死。

**温和争议点**：目的不在故意挑事。要找到一个大家都能吵、但不会让文章变薄的问题。比如「痛苦能不能抵消责任」「强势到底是有主见还是控制」「年轻人是不愿吃苦，还是不愿吃没回报的苦」。

**双方合理性**：先替两边都说一句人话。读者会因为你理解对方而更愿意听你后面的判断。

**未封死的问题**：结尾可以留下一个自然问题，邀请读者把自己的经历放进来。

示例：

> 所以这事光选边站没有用。公司当然要结果，员工也当然要活路。真正的问题是，当一个岗位长期靠消耗人的余量来维持，它到底还能不能叫正常管理？

## 3. 认同感公式

先替读者说出难处 → 再给出比情绪更深的机制 → 最后给一个可落地判断

读者愿意点赞，很多时候因为你把他心里那个含混的感受说清楚了。

写法顺序：

1. 先承认他的感受合理。
2. 再指出这个感受为什么会出现。
3. 然后解释背后的制度、关系、激励或信息差。
4. 最后给一个判断边界，不要无限上纲。

示例：

> 你觉得委屈，未必是玻璃心。这套关系里，责任被讲得很重，权利却讲得很轻。你真正介意的，是吃完这个苦以后，到底有没有人承认它的价值。

## 4. 开头四种写法

只学动作，不照抄句式。

这一节只用于快速理解。每次正式写作前，读取 `opening_playbook.md` 完成开头选型和重复度检查。

### 材料切口

适合新闻、通报、公共事件。

先拎一个最有重量的动作，再回答问题。

示例动作：通报里写了什么，他做了什么，谁做了什么决定，哪个细节最刺眼。

### 普通人切口

适合职场、情感、阶层、家庭议题。

先把读者带到一个普通场景里，再把问题抛出来。

示例动作：饭桌上沉默、下班后刷招聘、在聊天框里删字、站在医院缴费窗口前。

### 反直觉切口

适合大家已经形成一致骂声或一致赞美的题。

先给一个克制但不一样的判断，再解释为什么。

注意，只能反一层。反太多就像为了聪明而聪明。

### 自我切口

适合方法论、科技体验、产品体验。

先承认自己最初也误解了，或者自己也踩坑了，再带读者进入发现过程。

## 5. 正文推进

每 600 到 800 字至少要出现一次「落地段」。

落地段可以是：

- 一个人的 3 到 5 句画像。
- 一个具体动作线。
- 一个小对话。
- 一个材料里的细节回扣。
- 一个普通人会遇到的选择题。

不要连续三段都在讲抽象判断。判断要像钉子，场景才是木板。

## 6. 结尾怎么让人愿意评论

结尾不要硬喊「你怎么看」。更好的方式是把问题还给读者的生活。

可用方向：

- 回到开头那个具体人，看他最后真正面对的是什么。
- 留下一个边界问题，让读者讲自己的判断。
- 承认这事没有完美答案，但指出最该被看见的代价。

示例：

> 我不知道这个选择放到每个人身上会怎么做。但我很确定，很多人不是不知道正确答案，只是他们终于发现，正确答案也要有人替它付钱。

## 7. 各题型的评论入口

**社会议题**：责任和痛苦能不能同时成立。

**职场题**：结果导向和人的余量怎么平衡。

**情感题**：边界和冷漠、付出和讨好、强势和控制怎么区分。

**AI 科技题**：这个工具到底改变了普通人的工作，还是只让会用的人更强。

**产品体验题**：惊艳和翻车是否同时存在，用户愿不愿意为它改变习惯。

**热点评论**：大家第一反应之外，还有没有一个被忽略的具体人。
